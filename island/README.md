# 默绘的小岛

个人站点的 `/island/` 开放世界作品集。在约 800 × 600 米的自然岛屿中驾驶越野车、摩托与快艇，探索森林、山路、海岸和六个项目区域。WASD / 方向键驾驶、Shift 加速、空格刹车、拖动画面转镜头；手机支持摇杆、加速和刹车按钮。E / Enter 查看附近介绍，M 查看全岛，R 回到营地或港湾。项目手册提供全部作品列表，地点介绍可快速前往。

- `content.js` 按地区引用 `../persona/content.js` 的公开项目资料，避免维护两份项目描述。
- `world.js` 构建原创地形、树林和建筑；`vehicles.js` 构建三种载具；`main.js` 管理驾驶、陆地与水面约束、镜头、地图和介绍面板；`style.css` 提供桌面与移动布局。
- `vendor/` 是本地 Three.js 0.185.1 浏览器模块，许可随包保存。无第三方 CDN 请求，无打包步骤；沿用仓库现有 GitHub Pages 发布流程。
- 浏览：从仓库根目录启动静态 HTTP 服务，访问 `/island/`。

驾驶式作品集受到 [Bruno Simon](https://bruno-simon.com/) 启发，自然大岛与远距离探索参考 [Big Walk](https://bigwalk.game/) 的空间感；场景、模型和交互独立实现。个人简介与作品来自本人已有公开主页及 GitHub，不将项目展示表述为受委托的客户经历。

Howto

加一篇笔记

  1. 复制 blog/posts/steam-doorstop-bepinex.html 改标题和正文，文件名用英文短横线。
  2. 附件放到 blog/attachments/<同一 id>/。
  3. 在 blog/posts.json 的 posts 数组最前面加一条：
{
  "id": "new-slug",
  "title": "标题",
  "date": "2026-08-15",
  "tags": ["标签"],
  "summary": "一两句现象和结论。",
  "url": "posts/new-slug.html"
}

列表页按 date 倒序自动排。推到 main 后 GitHub Pages 会重新部署。

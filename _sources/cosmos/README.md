# COSMOS LAB · 太阳系引力实验室

浏览器里的三维太阳系物理模拟器。太阳、八大行星和月球均参与全体 EIH 1PN 广义相对论弱场计算；行星初态来自 JPL J2000 近似轨道元素，月球采用明确标注的教学相位。

## 使用

```bash
npm install
npm run dev
```

生产构建：`npm run build`，输出 `dist/`，发布路径为 `/cosmos/`。核心验证：`npm test`。

网站地址：[打开太阳系引力实验室](https://mohui666.github.io/cosmos/)。

## 操作

- 左侧切换全景、内太阳系、外太阳系和地月系统，选择任意天体。
- 手机上通过底部「天体」「参数」「显示」「数据」打开面板；选择天体后可直接修改它的参数，点击「应用参数」返回观察。
- 右侧「天体」支持单独查看、跟随，以及名称、颜色、质量、实际半径、位置和速度编辑。
- 「用轨道六根数设置此天体」可编辑半长轴、偏心率、倾角、升交点经度、近心点幅角及真近点角。
- 「物理」可调整引力倍率、请求步长、软化长度、Verlet/RK4、碰撞模式、恢复系数、碎裂阈值和碎片数量，并查看最近碰撞。
- 选择地球后点击「让此天体向太阳坠落」可验证地球—太阳接触；只移除相对太阳的初始速度，质量与半径保持不变。
- 选择一个天体，点击「向此天体发射撞击体」，设置质量比例、实际半径、初始相对速度和偏移量，再「发射并观察」。该实验加入真正参与引力计算的撞击体，并调整镜头、碰撞边界和演化速度以观察接触。
- 「显示」可调整轨迹、标签、参考轨道、网格、速度箭头及定位标记大小。实心球始终使用真实半径；空心定位环不代表体积，单独查看通过移动镜头靠近天体。
- 顶部保存/导入完整 JSON 实验；相机按钮导出当前画面。新增天体可用轨道或直接位置/速度。
- 空格播放/暂停；R 重置当前实验；F 显示全部；Esc 退出单体观察。鼠标拖动旋转、滚轮缩放、右键平移；触屏单指旋转、双指缩放平移。

单独查看仅改变显示，隐藏的天体仍参与引力计算。编辑天体时会暂停，点击应用后按播放继续。修改物理状态会开始新的能量参考段。恢复原始 JPL 近似初态请点击左侧「太阳系实验室」卡片；底部重置按钮重新开始当前实验，包括已加载的自定义初态。

## 物理模型

默认 EIH 1PN + 速度相关 RK4，真实光速。包含全体天体的速度项和势耦合，能量/动量观测使用同阶 EIH 表达式。可在「物理」切换牛顿对照；GR 模式不使用普通 Verlet 或 Plummer 软化。请求步长默认 0.00005 年，接触附近会细分并寻找最早接触。

**这是广义相对论弱场慢速近似，不是完整爱因斯坦场方程求解器。** 不包含高阶 PN、引力波、黑洞合并或相对论流体；相对论参数达到使用界限时明确暂停。史瓦西半径只是参照数值，不替换用户半径。

质量、实际半径相互独立，编辑质量只影响密度与引力；半径、位置和速度保持未编辑值。实心球与碰撞球共享半径，空心圆环用于定位。编辑造成重叠会在暂停时立即处理，模拟时间不增加。合并与碎裂本身可以改变体积。

碰撞默认开启，支持合并、吸收、反弹与受能量约束的引力聚合体碎裂。碎裂阈值和数量可调，碎片继续受引力；接触是明确的低速近似，未模拟材料与冲击流体。详细方程、边界和验证见 [SCIENCE.md](SCIENCE.md)。

本地验证包含孤立水星相对论进动约 **42.98 角秒/世纪**、有限质量二体 1PN 公式、完整太阳系一年 EIH 守恒、高速交叉与三维擦肩、暂停接触，以及浏览器中质量与半径的独立编辑。结果仅代表列出的测试初态和步长。

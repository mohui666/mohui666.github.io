# COSMOS LAB · 太阳系引力实验室

浏览器里的三维太阳系物理模拟器。太阳、八大行星和月球均参与直接成对牛顿引力计算；行星初态来自 JPL J2000 近似轨道元素，月球采用明确标注的教学相位。

## 使用

```bash
npm install
npm run dev
```

生产构建：`npm run build`，输出 `dist/`，发布路径为 `/cosmos/`。核心物理验证：`npm test`。

网站地址：<https://mohui666.github.io/cosmos/>。

## 操作

- 左侧切换全景、内太阳系、外太阳系和地月系统，选择任意天体。
- 右侧「天体」支持单独查看、跟随，以及名称、颜色、质量、实际半径、位置和速度编辑。
- 「用轨道六根数设置此天体」可编辑半长轴、偏心率、倾角、升交点经度、近心点幅角及真近点角。
- 「物理」可调整引力倍率、固定步长、软化长度、Verlet/RK4、碰撞模式和恢复系数。
- 「显示」可调整轨迹、标签、参考轨道、网格、速度箭头及显示大小。
- 顶部保存/导入完整 JSON 实验；相机按钮导出当前画面。新增天体可用轨道或直接位置/速度。
- 空格播放/暂停；R 重置当前实验；F 显示全部；Esc 退出单体观察。鼠标拖动旋转、滚轮缩放、右键平移；触屏单指旋转、双指缩放平移。

单独查看仅改变显示，隐藏的天体仍参与引力计算。编辑天体时会暂停，点击应用后按播放继续。修改物理状态会开始新的能量参考段。恢复原始 JPL 近似初态请点击左侧「太阳系实验室」卡片；底部重置按钮重新开始当前实验，包括已加载的自定义初态。

## 数值范围

距离为 AU，质量为太阳 GM 比例，时间为 Julian 年。默认 Δt = 0.00005 年，约 26.3 分钟；默认无引力软化。默认碰撞忽略接触，可手动切换合并或硬球模型。

这是明确模型下的数值近似，包含牛顿多体扰动，不包含相对论、天体内部或流体模拟，不能作为精密星历。显示大小、球面纹理和土星环用于观察；不参与引力或碰撞半径计算。详细公式、数据来源及已运行的核心检查见 [SCIENCE.md](SCIENCE.md)。

# COSMOS LAB · 太阳系引力实验室

浏览器里的三维太阳系物理模拟器。太阳、八大行星和月球均参与直接成对牛顿引力计算；行星初态来自 JPL J2000 近似轨道元素，月球采用明确标注的教学相位。

## 使用

```bash
npm install
npm run dev
```

生产构建：`npm run build`，输出 `dist/`，发布路径为 `/cosmos/`。完整核心物理与碰撞验证：`node --test tests/physics.test.js tests/collisions.test.js`。

网站地址：[打开太阳系引力实验室](https://mohui666.github.io/cosmos/)。

## 操作

- 左侧切换全景、内太阳系、外太阳系和地月系统，选择任意天体。
- 手机上通过底部「天体」「参数」「显示」「数据」打开面板；选择天体后可直接修改它的参数，点击「应用参数」返回观察。
- 右侧「天体」支持单独查看、跟随，以及名称、颜色、质量、实际半径、位置和速度编辑。
- 「用轨道六根数设置此天体」可编辑半长轴、偏心率、倾角、升交点经度、近心点幅角及真近点角。
- 「物理」可调整引力倍率、请求步长、软化长度、Verlet/RK4、碰撞模式、恢复系数、碎裂阈值和碎片数量，并查看最近碰撞。
- 选择一个天体，点击「向此天体发射撞击体」，设置质量比例、初始相对速度和偏移量，再「发射并观察」。该实验加入真正参与引力计算的撞击体，并切换真实尺寸、镜头和演化速度以观察接触。
- 「显示」可调整轨迹、标签、参考轨道、网格、速度箭头及显示大小。「使用真实天体大小」关闭视觉放大；接触半径辅助显示可用于核对碰撞位置。
- 顶部保存/导入完整 JSON 实验；相机按钮导出当前画面。新增天体可用轨道或直接位置/速度。
- 空格播放/暂停；R 重置当前实验；F 显示全部；Esc 退出单体观察。鼠标拖动旋转、滚轮缩放、右键平移；触屏单指旋转、双指缩放平移。

单独查看仅改变显示，隐藏的天体仍参与引力计算。编辑天体时会暂停，点击应用后按播放继续。修改物理状态会开始新的能量参考段。恢复原始 JPL 近似初态请点击左侧「太阳系实验室」卡片；底部重置按钮重新开始当前实验，包括已加载的自定义初态。

## 数值范围

距离为 AU，质量为太阳 GM 比例，时间为 Julian 年。默认 Δt = 0.00005 年，约 26.3 分钟；默认无引力软化。碰撞默认开启：低能接触合并，高能接触在能量预算允许时产生真实引力碎片。还可选择始终合并、可调恢复系数的硬球反弹或关闭碰撞。

启用接触模型时，积分会按引力与接近时间尺度细分请求步长，查找步内最早接触，处理碰撞后再积分余下时间。Verlet 检查二次漂移路径的内部极值；RK4 对试积分位置进行局部接触定位。高速端点穿越及引力聚焦的关键案例已验证，但这仍是有限步长数值近似，不是任意 N 体轨道的解析求解。初始重叠有限球体使用与力相匹配的核心势延拓，避免在处理接触前出现无穷能量。

碎裂模型比较质心系碰撞能和均匀球引力束缚能尺度，默认阈值倍率 1、碎片数 6（可设 2–12）。喷射能量最多取超阈碰撞能的 35%，同时扣除全系统势能变化与估计的自束缚分离功；保持质量、线动量及包含内部 `spin` 的总角动量。已有碎片继续受引力并在再次接触时再聚合；太阳吸收较小撞击体。该模型是明确的引力聚合体启发式近似，**不是 SPH、真实材料破坏或恒星流体模拟**。

这是明确模型下的数值近似，包含牛顿多体扰动，不包含相对论、天体内部或流体模拟，不能作为精密星历。显示大小、球面纹理和土星环用于观察；碰撞始终使用实际半径，观察模式中的大球体视觉重叠不代表物理接触。详细公式、能量记账边界、[原始碰撞研究](https://arxiv.org/abs/1106.6084)与实际验证结果见 [SCIENCE.md](SCIENCE.md)。

2026-09-05 本地 Node 验证 **14 项通过**：原有 7 项动力学检查加 7 项接触与碎裂检查，包含高速迎头、擦肩、引力聚焦、守恒量、碎片能量约束及重合初态。默认开启碰撞后，完整太阳系推进 1 Julian 年的最大相对能量误差仍为 **8.631 × 10⁻¹⁰**。这些数值只代表已验证的初态与步长，不能外推到任意实验参数。

# Cosmos Native 的物理范围

这是可运行的原生科学实验工作台。**不是完整宇宙模型，也没有实现完整爱因斯坦场方程。** 数值积分误差、方程近似误差、星历误差和流体分辨率误差是不同的量。

## 轨道

使用 JPL DE440s 的几何位置和速度作为初态；同时刻、太阳系质心、ECLIPJ2000 坐标，时间变量为 TDB。月球与地球分开，火星及外行星采用系统质心与系统 GM，包含冥王星系统。界面时间转换为 UTC。星历回放与自行积分是两种明确的模式。

REBOUND 5.1.1 的 IAS15 自适应十五阶积分器；REBOUNDx 5.1.0 的 gr_full 提供全体天体一阶后牛顿项。gr_full 的名称不表示完整广义相对论。加入太阳与地球的轴对称 J₂ 引力及反作用力，方向固定于 J2000 自转轴。能量包含 1PN 哈密顿量与 J₂ 势。

不包含其他行星的独立卫星、小行星群、地月潮汐耗散、随时间变化的地球引力场、恒星演化、引力波或强场时空。J₂ 轴固定，无法预报长期自旋进动。任意设置超出弱场慢速范围会停止；不通过缩放光速伪造相对论。

以 2026-09-05 00:00:00 UTC 初值推进 365.25 天：地球日心位置与 DE440 相差约 0.109 km，月球约 0.769 km；相对能量变化约 1.1×10⁻¹⁵。此差异只适用于该场景。降低 IAS15 误差容限不能消除模型中缺少的物理项。

质量编辑与半径独立。轨道模型的实际球面接触时停止，保留质量、速度和接触状态；不会用人为碎片生成代替物质计算。可以将三维接触状态转交给一个独立的两体流体实验；转交不等于轨道与流体的同步双向耦合。

## 流体与材料

使用编译运行的 SWIFT 2026.04：REMIX SPH、Wendland C2 核、约 100 个邻居、自适应时间步与牛顿自引力多极展开。内能、压力、密度和材料标记随物质粒子一起演化。没有预设碎片数量、合并阈值或视觉爆炸决定物理结果。

岩质模型使用 ANEOS Fe85Si15 核心和 forsterite 地幔。WoMa 从给定质量、半径、表面温度和压力求球形静水平衡及核心边界，SEAGen 放置粒子。有限分辨率造成的质量归一化系数记录于 experiment.json；不会改输入半径。该温度与材料模型不代表现代地球的完整内部结构。快速自转采用球形初态叠加速度，未求旋转平衡。

恒星示例采用 n=3 Lane–Emden 多方结构和 γ=5/3 理想气体。没有真实太阳内部模型、辐射输运、核反应或磁场；不能把它视作精确地球坠入真实太阳的预报。

每一项流体结果应检查：独立初态松弛、粒子数增加后的收敛、引力软化尺度、时间步和状态方程适用范围。默认低分辨率实验标注“未证明收敛”。太阳与地球质量相差约 33 万倍；当前默认多质量粒子只适合探索，不能同时解析整个太阳和地球的完整破坏。

原始初态、实际求解配置、材料分布、HDF5 快照、守恒量和错误日志保存在 runs/ 下。时间轴显示实际求解快照；材料颜色不代表温度。能量图为动能、内能与引力势能之和的相对变化，不把数值误差伪装成辐射。

## 本次实际验证

- 原生轨道检查：一年星历对比、独立质量/半径、暂停重叠接触与场景往返、地球—太阳接触时间对照、n=1 Lane–Emden 与 sin(ξ)/ξ 解析解均通过。地球自由坠落约 65.37084670 天接触太阳；将外部最大步长从 0.25 天增至 2.5 天，接触时刻差小于 0.01 秒。
- REMIX 三维 Sod 激波，γ=5/3、t=0.2：36,864 与 124,416 粒子，对独立精确 Euler Riemann 解的体积加权密度 L₁ 误差分别为 0.02941 与 0.02353（左态密度为 1）。最大能量相对变化约 0.115% 与 0.123%。空间误差下降，但不是所有误差都单调下降。
- 原地球与 0.133 地球质量撞击体，接触速度 12 km/s、角度 30°、演化 2,400 秒：5,956 粒子/100 km 软化与 23,211 粒子/50 km 软化均完成，所有物质粒子保留，输出有限。最大总能量相对变化分别为 0.429% 与 0.273%；末态总内能相差约 4.5%。这是联合提高空间分辨率的对照，尚不足以证明撞击结果收敛。
- 18,830 粒子的孤立岩质目标演化 2,400 秒：95% 粒子半径变化约 −0.072%，残余速度 RMS 约 14.2 m/s。此初态稳定性检查仅对应该温度、材料和分辨率，不能推广到快速自转或任意质量半径。
- 10,407 粒子的多方恒星—地球探索实验完成 200 秒，但其全局能量误差预算大于地球撞击能量尺度，**不能据此判定真实地球在太阳中的破坏细节准确**。
- WSLg 实际桌面窗口：中文、质量/半径独立编辑、逐体显隐、接触转交、材料/密度回放及从界面启动真实 SWIFT 至自动回放的完整流程通过。未验证独立 Windows exe、手机端或其他机器。

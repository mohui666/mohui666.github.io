# Cosmos Native

太阳系轨道与多材料碰撞的原生桌面工作台。Python / Qt / OpenGL 界面，C 语言 REBOUND、REBOUNDx 与 SWIFT 后端。当前支持 Linux 桌面、Windows 11 下的 Ubuntu WSLg。

**这台电脑已经安装完成。双击 Windows 桌面的「宇宙模拟器.cmd」启动。**

首次安装到其他电脑：在 Ubuntu 24.04 的项目目录执行 `bash scripts/install.sh`，随后 `bash run.sh`。需要网络下载星历、材料表、依赖及源码，并编译 SWIFT；不是免安装 Windows exe。安装后正常实验无需联网。依赖、数据与后端约占 1.7 GB，运行数据另计。

## 操作

- 「轨道与天体」：JPL 日期初值、IAS15 积分、1PN 和 J₂ 开关，独立显示并编辑天体质量、半径、位置和速度。质量编辑不改半径。双击天体列表或点击聚焦按钮查看实际球面。
- 「让此天体向太阳自由坠落」：去除该天体相对太阳的初速度，积分至真实表面接触。可将捕获的三维相对位置、速度转入流体实验。
- 「JPL 星历回放」：查看星历中太阳系的状态，和可修改的动力学实验分开。
- 「物质碰撞」：设置两个天体各自的质量、半径、粒子数、温度、自转，以及接触速度、角度、时间、CFL 和引力软化。计算完成后，拖动时间轴回放 HDF5 快照，按材料、密度或比内能着色。
- 「打开已有实验目录」：本机 runs/ 中已有岩质撞击和多方恒星实验。输入表会恢复为所打开实验的实际配置。
- 保存场景为 JSON；流体实验保存实际配置、初态、材料表引用、HDF5 快照、守恒量和运行日志。关闭窗口后已启动的批处理继续运行；需要终止时先点击「停止当前计算」。

## 准确性

请先读 [SCIENCE.md](SCIENCE.md)。轨道是全体天体 1PN 弱场模型；流体是牛顿自引力 SPH。没有完整爱因斯坦方程、辐射磁流体、核反应、固体强度断裂或同步双向轨道—流体耦合。恒星是多方模型，不是真实太阳全物理模型。

当前默认碰撞粒子数用于探索，不代表分辨率已收敛。特别是地球—太阳巨大的质量、尺度差异，不能用数千粒子的图像声称完整破坏过程准确。初态为球形静水平衡剖面的离散化，独立松弛和分辨率检查仍是每个研究实验的必要步骤。

定向验证：

```bash
.venv/bin/python tests/test_orbits.py
.venv/bin/python tests/sod_validation.py
.venv/bin/python tests/gui_smoke.py
```

GUI 冒烟脚本使用本机已生成的 runs/impact-4096-v2 数据。Sod 验证脚本运行原生 REMIX 并与独立 Euler Riemann 解析求解器比较；不是将程序自身的结果当参考答案。

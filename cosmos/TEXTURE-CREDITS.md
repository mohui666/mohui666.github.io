# 太阳系纹理署名 / Solar texture credits

本项目使用的太阳、八大行星和月球纹理由 **INOVE / Solar System Scope** 制作，来自 [Solar System Scope — Solar Textures](https://www.solarsystemscope.com/textures/)。

这些纹理由作者按 [Creative Commons Attribution 4.0 International（CC BY 4.0）](https://creativecommons.org/licenses/by/4.0/) 许可发布。作者网站：[INOVE](https://www.inove.eu.com/)、[Solar System Scope](https://www.solarsystemscope.com/)。

本项目于 2026-09-05 下载官方 2k JPEG 原图，仅将文件名改为天体 ID；**源图内容未修改**，未裁切、调色或重新编码。三维场景的光照、显示大小和材质设置只影响呈现方式。

作者说明，这组等距柱状投影纹理基于 NASA 高程与影像数据，并参考航天器照片调整色彩；部分缺少测绘数据的区域使用补绘，饱和度有所增强。因此它们是基于观测资料制作的可视化贴图，不是实时观测图像。金星使用大气外观图，地球使用白昼图。
